 CampusLink - Teacher Dashboard

## Teacher Dashboard Features

### 📊 Dashboard Overview
- Summary cards showing key stats (students, classes, assignments)
- Quick access to all teacher modules

### 📅 Attendance Management
- Mark and track student attendance
- View attendance history and reports

### 📚 Materials Upload
- Upload and manage study materials
- Share files with students by subject

### 📝 Assignments
- Create and assign tasks to students
- Track submissions and deadlines

### 👥 Student Management
- View student lists per class
- Monitor student performance
